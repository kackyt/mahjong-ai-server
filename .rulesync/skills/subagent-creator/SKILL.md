# Subagent Creator

新しいサブエージェントを対話的に作成・テスト・保存するスキルです。

## 1. 要件定義

ユーザーに以下の情報をヒアリングします（不足している場合は質問してください）：
- **名前**: サブエージェントの名前（英数字・ハイフンのみ、例: `code-reviewer`）
- **目的と概要**: 何をするサブエージェントか？
- **ターゲット**: どのようなケースやファイルパターンで呼び出されるべきか？ (例: `targets: ["*"]` や `["*.ts"]`)
- **指示の詳細**: サブエージェントが従うべきルールや制約、プロンプトの具体的な内容。

## 2. 定義ファイルの作成

要件が明確になったら、以下のフォーマットに従ってサブエージェントの定義ファイルを作成します。
保存先は `.rulesync/subagents/<subagent-name>.md` です。

```markdown
---
name: <subagent-name>
targets: ["<ターゲットパターン>"]
description: >-
  <サブエージェントの概要とトリガー条件の詳細>
model: inherit
---

# 役割と指示
<具体的なプロンプトやルール、制約などをここに記述します>
```

※ YAMLフロントマターは必ず必要です。

## 3. テストとレビュー

下書きを作成し `.rulesync/subagents/<subagent-name>.md` に保存した後、ユーザーに通知 (`notify_user` などを利用) してファイルのレビューを求めます。
- **ヒント**: ユーザーが具体的なケースで試したいと言った場合は、Antigravity上でそのケースを想定したタスクを実行して動作検証を行ってください。

## 4. 完了

ユーザーからの修正指示があれば対応を返し、最終的に承認されたら、サブエージェント作成完了の旨を報告して終了します。
